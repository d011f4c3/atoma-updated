# Task 0158 — Animated About readers and stronger sample studies

## Request

The owner requests better right-side sample studies, About entries that open as
popups, and an About experience with purposeful animation and visual interest.
The harvest remains a separate, first field-note entry; ATOMA's approach,
company and relationships still lead About. This request supersedes Task 0156's
normal click-through behavior while keeping the standalone entry URLs usable.

## Scope

- Open About entries as native modal readers over the current page. Preserve
  background position and focus on return, with close, Escape, backdrop and
  browser Back/Forward. Keep native entry hrefs for no-JavaScript and modified
  clicks. Use inset mobile dialogs and a persistent close control.
- Give each reader full-proportion photography with interspersed existing field
  observations, a reading-progress cue and brief opening/closing motion.
- Animate the About composition through photographic reveals, staggered reading
  sections, drawn rules, the site's existing title resolution, restrained image
  movement on scroll, and photographic previews on entry hover/focus. Preserve
  the readable document without scripting and respect reduced motion.
- Extend the right-side sample study with a photographic set folio, persistent
  companion dock and expandable application comparison. Retain earlier options,
  product/quantity/material continuity and the canonical left-only homepage.
- Preserve the selected Connected Shop treatment, current Samples page, all
  supported locales, both themes, truthful commerce states and client facts.

No new dependencies, fabricated technical claims, commerce setup or deployment.
